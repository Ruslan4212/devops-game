# Карта проекта — что где лежит

Читать перед началом любой работы вместо повторного исследования репозитория.
`index.html` — собранный файл, его не редактируют напрямую: правки идут в
`p*.txt`, потом `bash build.sh`. Порядок склейки и назначение каждого файла —
в `build.sh` (комментарии там всегда актуальны, при добавлении файла обновлять
и `build.sh`, и этот раздел).

## Рабочие процедуры

```bash
bash build.sh              # пересобрать index.html из p*.txt
git add -A && git commit -m "..." && git push
```

Локальный запуск для тестов через браузерный инструмент:
`.claude/launch.json` в корне `D:\AIagent` уже настроен (`python -m http.server
8765 --directory devops-game`) — `preview_start` с `name: "game"`, открывается
`http://localhost:8765/index.html`. После правки файла и `build.sh` — просто
`navigate` на тот же URL (или `location.reload()`), сервер раздаёт свежий файл.

Smoke-тест после любой правки контента (вставить в `javascript_tool`):
```js
const bad=[];
WORLDS.forEach(w=>w.miss.forEach(m=>{
  const ds=m.ch.map(c=>c.d||0);
  if(m.ch.length<5||ds.some(d=>!d)||!ds.includes(5)||m.cards.length<4)
    bad.push(w.id+'/'+m.id);
}));
const dup=(()=>{const s=new Set(),d=[];WORLDS.forEach(w=>w.miss.forEach(m=>{
  if(s.has(m.id))d.push(m.id);s.add(m.id)}));return d})();
JSON.stringify({bad,dup,totals:totals()})
```
`totals()` — встроенная функция игры, суммирует миры/миссии/задания/лаборатории.

## Ключевые глобальные объекты (для быстрого grep)

- `WORLDS` — массив 11 миров, каждый `{id, n, ic, tag, desc, miss:[...], boss:{...}}`
- `LABS` — объект лабораторий по id
- `DR` — массив команд тренажёра `{w, q, a:[варианты]}`
- `JOBS` — вакансии карьеры
- `S` — текущее состояние игры (localStorage), `S.life` — жизненный слой
- `R` — текущий раннер миссии/лаборатории (не персистентный, только в памяти)
- `totals()` — сводная статистика по всей игре (используется в smoke-тесте)
