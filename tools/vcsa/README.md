# find_orphaned_vmdk.py — неподключённые диски на датасторах vCenter

Скрипт обходит все датасторы vCenter (VCSA) и ищет `.vmdk`, которые не подключены
ни к одной виртуалке или шаблону. **Только чтение**: ничего не удаляет и не меняет.

## Как работает

1. Через PropertyCollector собирает диски всех ВМ и шаблонов в каждом датацентре:
   - текущие диски (`config.hardware.device`) вместе со всей цепочкой родителей
     (снапшоты, linked clone);
   - все файлы дисков из `layoutEx.file`.
2. Обходит каждый доступный датастор через `HostDatastoreBrowser.SearchDatastoreSubFolders`
   с `VmDiskFileQuery`. API возвращает только дескрипторы, без `-flat`/`-delta`, а `fileSize`
   уже включает данные диска.
3. Всё, что нашлось на датасторе и не принадлежит ни одной ВМ, выводится списком
   от самых больших к самым маленьким.

## Запуск

Запускай с любой машины, откуда открывается vCenter на 443 порту. На самом VCSA `pip` обычно нет.

```bash
pip install pyvmomi
```

```bash
export VC_PASSWORD='секрет'
./find_orphaned_vmdk.py -s vcsa.lab.local -u administrator@vsphere.local --insecure
```

```bash
./find_orphaned_vmdk.py -s vcsa.lab.local -u administrator@vsphere.local \
  -d datastore01 -d datastore02 --min-age-days 30 --csv orphans.csv
```

| Флаг | Что делает |
|---|---|
| `-d/--datastore` | проверять только указанные датасторы (можно повторять) |
| `--min-age-days N` | показывать только диски, не менявшиеся N дней |
| `--include-hidden` | искать и в скрытых каталогах (`.snapshot`, `.sdd.sf`, `.vSphere-HA`…) — по умолчанию пропускаются |
| `--no-fcd` | не запрашивать First Class Disks |
| `--csv` / `--json` | сохранить результат в файл |
| `--insecure` | не проверять сертификат vCenter (самоподписанный) |

Хватает роли **Read-only** на уровне vCenter плюс привилегии *Datastore → Browse datastore*.

## Прежде чем удалять

В списке могут оказаться диски, которые нельзя удалять, хотя ВМ к ним не подключена:

- **FCD / CNS** (Kubernetes PV, vSphere CSI) — помечаются как `FCD '<имя>'`. Отключённый
  persistent volume тоже считается FCD, удалять его нужно через Kubernetes или CNS.
- **Content Library** (`contentlib-*`) — шаблоны библиотеки.
- **Общие датасторы нескольких vCenter** — скрипт видит ВМ только своего vCenter.
- **ВМ в состоянии inaccessible/orphaned** — без конфигурации её диски не видны, скрипт об этом
  предупреждает.
- **vSAN** — пути дисков могут отличаться (UUID вместо имени папки). Если имя файла совпадает
  с диском какой-либо ВМ, диск помечается как «вероятно, тот же диск».
- Диски, которые прямо сейчас копируются, или резервные копии, сделанные руками
  (`vm.vmdk` в папке `old/`).

Перед удалением переименуй диск или перенеси его в карантинную папку и подожди пару недель.
