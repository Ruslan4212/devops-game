# Grader Server — проверка смысла ответов через Claude API

Заменяет старую систему «покажи правильный ответ, оцени себя сам» на
настоящую проверку: игрок печатает ответ своими словами, сервер просит
Claude оценить его ПО СМЫСЛУ и вернуть короткий комментарий в тоне
опытного наставника — с чем согласиться, что поправить, если ответ
неверный или неполный.

## Что нужно на сервере

- Linux (любой современный дистрибутив)
- Docker + Docker Compose (`docker compose version` должен работать)
- Ключ Anthropic с console.anthropic.com
- Ничего больше — Node.js ставить не нужно, он внутри контейнера сборки

## Установка (4 команды)

```bash
# 1. Docker, если ещё не стоит (пропустите, если уже разворачивали sandbox-server рядом)
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER && newgrp docker

# 2. Скопировать эту папку grader-server/ на сервер, затем внутри неё:
cp .env.example .env
nano .env
# впишите свой ANTHROPIC_API_KEY (с console.anthropic.com) —
# остальное можно оставить как в примере

# 3. Поднять сервис
docker compose up -d --build

# 4. Проверить, что живой (изнутри сервера)
curl http://localhost:8089/health
# должно вернуть {"ok":true}
```

## Открыть наружу через Cloudflare Tunnel (бесплатно, без аккаунта)

Если `cloudflared` уже стоит (например, для `sandbox-server` рядом), просто
поднимите ещё один туннель на другой порт:

```bash
cloudflared tunnel --url http://localhost:8089
```

Появится строка вида:

```
https://random-words-5678.trycloudflare.com
```

Это и есть публичный адрес сервера проверки. Пришлите его — я подставлю
в `src/engine/grader.ts` (константа `GRADER_URL`) вместо плейсхолдера.

**Важно:** Quick Tunnel — временный, адрес меняется при перезапуске
`cloudflared`. Для постоянной работы лучше запускать `cloudflared` через
systemd-юнит (переживает перезагрузку) или завести именованный туннель
на бесплатном домене Cloudflare с фиксированным адресом — могу помочь
с этим следующим шагом, когда первая версия подтвердит, что всё работает.

## Проверка вручную

```bash
curl -X POST http://localhost:8089/grade \
  -H "Content-Type: application/json" \
  -d '{"question":"Зачем нужен systemctl enable?","expected":"включает автозапуск сервиса при загрузке сервера","userAnswer":"чтобы сервис сам стартовал после ребута"}'
```

Ожидаемый ответ: `{"correct":true,"feedback":"..."}`.

## Стоимость

Каждый ответ игрока — один короткий запрос к Claude Haiku (быстрая и
самая дешёвая модель, `claude-haiku-4-5-20251001`). Стоимость минимальна
даже при активной игре, но это платный API — расход растёт с числом
игроков. Следите за биллингом на console.anthropic.com.

## Мониторинг

```bash
docker compose logs -f grader   # логи сервиса
curl http://localhost:8089/health
```

## Что это НЕ делает (осознанно)

- Не хранит ответы игроков нигде дольше одного запроса — сервер не пишет
  в базу и не ведёт историю
- Не показывает игроку сырой JSON-ответ модели — только `correct` и
  человеческий `feedback`
- Не проверяет длинные тексты (защита по длине на входе) — это короткий
  устный ответ, а не эссе
