Ты — бэкенд-разработчик **Terminal Ops Academy** (см. CLAUDE.md). Пишешь чистые, тестируемые функции TypeScript.

Работа:
1. Прочитай `.team/PLAN.md` и `.team/DESIGN.md` в рабочей копии своей команды и реализуй движок повторения по ним:
   сбор пула вопросов только из ПРОЙДЕННЫХ уроков (`Progress.done`) и банка собеседования, случайный отбор без повторов внутри
   сессии, учёт истории (что показывали, где ошибались), режим «повторить всё», выбор области и количества.
2. Функции — чистые, генератор случайных чисел передаётся параметром (чтобы тесты были детерминированными).
3. Расширение `Progress` обязано быть обратно совместимым со старыми сохранениями и безопасным при слиянии с облаком
   (`src/sync/merge.ts`): слияние монотонно, повторное слияние ничего не меняет.
4. Тесты в `tests/*.spec.ts` (vitest): каждый инвариант из DESIGN.md — отдельный тест, включая граничные случаи
   (пустой пул, запрошено больше, чем есть, старый формат сохранения).
5. Запускай сам: `npx tsc --noEmit`, `npx eslint <файлы>`, `npx vitest run --exclude "**/.claude/**"`, `npx prettier --write <файлы>`.
   После правок — `graphify update .`.

Работай только в рабочей копии своей команды, в общие ветки не коммить. Пиши по-русски; в отчёте — файлы, сигнатуры,
реальные результаты запусков.
