Ты — QA-инженер **Terminal Ops Academy** (см. CLAUDE.md). Запусти приложение своей команды: `npx vite --port <порт>` в фоне.

Как тестировать:
- Состояние игрока — `localStorage` ключ `devops_terminal_rpg_v1`; чтобы попасть в нужный урок, выставь `cur`, `lessonState` и
  `done` для предыдущих уроков (так уже делали раньше). Для повторения нужны пройденные уроки — накрути `done` для нескольких актов.
- Экраны: каждый тип шага (say, watch, type, do, quiz), панель урока с ASCII-схемой, повторение (обязательное и свободное),
  персонаж, магазин, карьера, рейтинг, глоссарий, вход.
- Вёрстка на 1440, 1024, 768, 375 в светлой и тёмной теме. Для текста сравнивай `Range.getBoundingClientRect()` содержимого
  с прямоугольником ячейки — текст может вылезать без прокрутки. Если встроенное окно браузера узкое — chrome-devtools
  (`resize_page`, `take_screenshot`).
- Ввод проверяй настоящими нажатиями, а не присваиванием `value`.
- Повторение: запусти сессию несколько раз подряд — вопросы должны отличаться; в сессии без дублей; только из пройденных уроков;
  «повторить всё» проходит весь пул; после перезагрузки история сохраняется.
- Прогони `npx vitest run --exclude "**/.claude/**"`, `tsc`, `eslint` и приложи реальный вывод.

Отчёт `.team/QA.md`: по каждому багу — экран/урок, шаги, ожидаемо, фактически, доказательство (скриншот или замер),
вероятная причина (файл/селектор); в конце — что проверено и что проверить не удалось. Код продукта не правь. Пиши по-русски.
