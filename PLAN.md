## Формат "новых" миссий (эталон — p26.txt, мир Linux l1-l5)

Каждая миссия:
- `cards`: 4-8 карточек теории. У карточек, где есть конкретная команда/приём:
  - `cheat: "команда — что делает"` — короткая строка для шпаргалки
  - `t: {q, ans, hint, why}` (для команды) или `{q, a, c, why}` (выбор) —
    отработка сразу после этой карточки; печатается кнопка «Отработать →»
  - в тексте `b` — блок `<b>Зачем в жизни:</b>` с конкретным сценарием
- `ch`: 5-6 заданий строго по возрастанию `d:1..5`:
  - d1-d2: короткие, можно `t:"c"` (набрать команду) или `t:"q"` (выбор) — но
    предпочтение отдаём набору руками даже на d1-d2, если команда короткая
  - d3-d5: **только** `t:"c"` (команда) или `t:"f"` (заполнить пропуск) —
    никаких вариантов ответа на этом уровне сложности
  - d5 обязателен и это разбор инцидента: сценарий, набор команды-решения

Движок (p9.txt) уже поддерживает: переход теория→отработка→теория,
шпаргалку по кнопке во время заданий, платную подсказку (200₽ из S.life.money).
Менять движок дальше не нужно, если не попросят — только контент.

### Блок C — новые миры (создать с нуля, тот же уровень глубины и формата)
Каждый — новый файл(ы), новая запись в `WORLDS`, добавить в `build.sh`,

**Как создать новый мир (см. C1/Zabbix как пример):**
1. В `p6.txt` добавить объект в массив `WORLDS`: `{id, n, ic, tag, desc, miss:[], boss:{...}}`,
   `miss:[]` — пустой, реальные миссии придут из нового файла. Не забыть запятую
   между элементами массива (частая причина синтаксической ошибки).
2. Создать новый файл `pN.txt` (следующий свободный номер) с
   `W("id").miss.length=0; W("id").miss.push(...)` — миссии сразу в новом
   формате (cheat/t на карточках, d1-d5 лесенка, d3-d5 только `t:"c"`/`"f"`).
3. Зарегистрировать `pN.txt` в `build.sh` (в блоке новых миров, после p25.txt).
4. `bash build.sh` → smoke-тест (структурные проверки + проверка, что новый
   мир реально загрузился: `W("id").miss.length`, `W("id").boss`).
5. Обновить `MAP.md` (строка `p6.txt`, новая строка для `pN.txt`, счётчик миров
   в разделе "ключевые объекты").
